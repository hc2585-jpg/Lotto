물론 로또는 완전한 무작위이므로 재미 목적으로 활용하세요! 😊

📌 기본 사용 흐름 1. 홈 / 추천번호 탭에서 전략을 선택하고 추천번호 5세트 확인
2. 매주 토요일 추첨 후 → 회차 추가 탭에서 1등 당첨번호 입력
3. 저장하면 자동으로 데이터에 반영되어 다음 분석에 사용됩니다
4. 빈도 분석에서 어떤 번호가 자주 나왔는지 확인

⚖️ 전략 설명 • 균형형: 고빈도 2개 + 중간 2개 + 저빈도 2개를 섞어 균형잡힌 조합 생성
• 핫번호: 최근 100회에서 가장 많이 나온 번호 위주로 선택
• 냉각번호: 최근 50회에서 한 번도 안 나왔거나 적게 나온 번호 위주
• 미출현 우선: 마지막 출현 이후 가장 오랜 시간이 지난 번호 선택
• 랜덤 혼합: 위 전략들을 무작위로 섞어서 다양하게 생성

☁️ 구글 시트 동기화 • 회차 추가 시 자동으로 구글 시트에 저장됩니다
• 상단 ☁️ 불러오기: 구글 시트 데이터를 현재 기기로 가져오기
• 상단 💾 저장하기: 현재 데이터를 구글 시트에 강제 저장
• 다른 기기(폰 등)에서 사용 시: 파일 열면 자동으로 시트에서 불러옴
• 인터넷 없을 때는 로컬 데이터로 동작 (상단에 상태 표시)
